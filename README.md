# ARCHÉ Studio — Architecture & Interior Design website + admin

Next.js 16 (App Router) · React 19 · Tailwind CSS v4 · Prisma 7 / PostgreSQL · framer-motion · Nodemailer.
Transformed from the original physiotherapy codebase — same stack, auth, APIs and database (additive migration only).

## Getting started

```bash
npm install
cp .env.example .env.local        # fill in values
npx prisma migrate deploy         # apply migrations
npm run db:seed                   # LOCAL ONLY — sample studio content (refuses non-local DBs)
npm run dev
```

Admin: `/login` (password = `ADMIN_PASSWORD`) → `/dashboard`. Email templates: `/email-preview`.

Scripts: `dev`, `build`, `start`, `lint`, `typecheck`, `db:seed`.

## Rebranding

- Name / wordmark / tagline: `lib/brand.ts` (or `NEXT_PUBLIC_BRAND_*` env vars).
- Contact, address, hours, stats, hero image, socials: **Dashboard → Studio Settings** (DB), with `data/studio.json` as fallback.
- Design tokens (colours, fonts, buttons, fields): `app/globals.css` (`@theme`). Fonts via `next/font` in `app/layout.tsx`.

## Domain mapping (DB names kept for compatibility)

| Table / API | Shown as |
|---|---|
| `Booking` · `/api/bookings`, `/api/admin/bookings` | Enquiries / consultation requests (`problem` = project brief) |
| `Project` · `/api/admin/projects` *(new)* | Projects + public portfolio |
| `TeamMember` · `/api/admin/team` *(new)* | Team |
| `ClinicSettings` · `/api/admin/clinic` | Studio Settings |
| `Profile` · `/api/admin/profile` | Principal Architect |
| `Certification` | Awards |
| `Tip` | Design Principles |
| `Event` / `Workshop` / `Session` | Journal: News, Talks & Site Visits, Films |
| `GalleryItem` | Studio Archive |

Clients are derived from enquiries + projects (grouped by email) — no separate table.

## Deployment (Vercel + Prisma Postgres / Neon + Cloudinary)

- Vercel runs `vercel-build` = `prisma generate && prisma migrate deploy && next build`,
  so every deploy applies pending migrations to the production database automatically.
- The DB URL is resolved from `DATABASE_URL`, then `POSTGRES_URL`, `DATABASE_URL_UNPOOLED`,
  `POSTGRES_URL_NON_POOLING` — the first direct `postgres://` URL wins (`prisma+postgres://`
  Accelerate URLs are ignored; use the *direct* connection string).
- First-time starter content: `SEED_ALLOW_REMOTE=1 DATABASE_URL="<prod url>" npm run db:seed`.

## Deployment notes

- Vercel cron (`vercel.json`) still calls `/api/cron/check-appointments` daily; it now sends a polite "let's find a new time" email.
- Set `SITE_URL` to the new domain, and Cloudinary for uploads on Vercel.
- Sitemap is generated by `app/sitemap.ts` (the `next-sitemap` postbuild step was removed; the package can be uninstalled).
